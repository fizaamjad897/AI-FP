# Security policy

## Scope

The maintained scripts and the default branch are the supported code surface. Historical notebooks, archived outputs, datasets, and model artifacts are research materials and do not have a clinical support guarantee. There is no hosted inference service in this repository.

## Reporting

Report vulnerabilities or exposed sensitive data privately through [GitHub's vulnerability reporting form](https://github.com/fizaamjad897/Knee-Osteoarthritis-Grading/security/advisories/new). Do not include credentials, patient identifiers, or private images in public issues. If the form is unavailable, use GitHub Support's private reporting channel rather than publishing the sensitive material.

Include the affected commit, relevant file paths, impact and a minimal reproduction that avoids private data. The maintainer will assess the issue and coordinate a fix; no guaranteed response SLA is claimed.

Review notebook code before execution. Only load model files from trusted sources, and keep packages patched. Data-licensing and scientific-validity concerns can be raised without sharing private records.
