A fine-tuned Xception network reads one knee X-ray, assigns it a Kellgren-Lawrence grade from 0 to 4, and shows the regions that decided it.

The Kellgren-Lawrence scale

Radiologists grade knee OA by eye. The model has to learn the same five steps.

The pipeline, start to finish.

Redrawn from the architecture diagram in the paper.

1

Data preparation

  • Raw X-rays, foldered by grade
  • Environment and directory setup
2

Processing

  • 80 : 20 train / test split
  • Class counts verified
  • Random samples checked by eye
3

Augmentation

  • Image generators, 224 × 224
  • Flips, shifts, zoom, brightness
  • Class weights for imbalance
4

Model development

  • InceptionResNetV2
  • ResNet-50
  • Xception
  • DenseNet201

ImageNet weights, fine-tuned end to end. GAP, dropout 0.2, five-way softmax.

5

Train and evaluate

  • Weighted cross-entropy
  • Early stopping on val loss
  • Confusion matrix, ROC
6

Explain

  • LIME superpixels
  • SHAP partition values
  • Served in Streamlit
