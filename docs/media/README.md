# Project reel

- [Watch or download the MP4](knee-oa-reel.mp4).
- [Original HTML source](knee-oa-reel.html).
- [Capture metadata](reel-metadata.json).

The video records the existing `portfolio-fiza/public/motion/knee-oa-reel.html` presentation. Its 12 scenes run for 100.2 seconds. The square composition, embedded source images, fonts and animation timing were preserved; outer playback controls were excluded. The source HTML is unchanged from the portfolio file. Google Fonts require network access when opening the HTML.

Frames were sampled in Chromium at exact animation offsets and encoded as H.264 MP4. The source SHA-256 and encoding dimensions/frame rate are recorded in the metadata file. This export has no audio.

The Streamlit-style interface is illustrative. Scores and explanation examples come from the historical presentation, not a new inference or training run. Read the [research limitations](../KNOWN_ISSUES.md) and [asset-licensing notes](../ASSET_LICENSING.md) before interpreting or reusing the reel.
